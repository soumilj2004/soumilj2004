### Featured Projects

#### [SteelSight](https://github.com/soumilj2004/SteelSight) — Satellite Commodity Intelligence
- Unsupervised SWIR thermal-anomaly pipeline over Sentinel-2 imagery — 45 Chinese steel facilities, 2,815 monthly composites, **zero labelled data**.
- Validated as a **2-month leading indicator** of World Steel Association output (R²=0.173, p=0.0003).
- Flagged the Aug 2021 activity peak **8 weeks before** a 56% iron-ore price collapse. IEEE-format paper authored.

<sub>Python · Google Earth Engine · Rasterio · SciPy · FastAPI · React</sub>

#### [NeuroEvo](https://github.com/soumilj2004/NeuroEvolution-neural-network-build) — Gradient-Free Network Evolution
- Game-agnostic framework evolving neural networks by genetic algorithm — **no backpropagation**, flat 4,060-weight genomes, one adapter per environment.
- Measured generalisation on held-out procedurally generated mazes, exposing an **18.4-point memorisation gap** and reducing it to **2.7**.
- Live network visualiser showing inputs, activations and action scores beside the running game.

<sub>Python · NumPy · Genetic Algorithms</sub>

#### [Agentic LLM Compression Lab](https://github.com/soumilj2004/agentic-llm-compression-lab) — Multi-Agent Benchmarking
- Five coordinated agents automating end-to-end LLM compression evaluation on TinyLlama.
- Benchmarked FP32 vs. magnitude-pruned across latency, throughput, memory and quality — **~83% latency cut** (4.48s → 0.74s).
- Streamlit dashboard so the accuracy-vs-speed trade-off is read rather than guessed at.

<sub>Python · PyTorch · HuggingFace Transformers · Streamlit</sub>

#### [AgriVision AI](https://github.com/soumilj2004) — Offline Crop Disease Detection
- MobileNet-V2 classifier (92.7% test accuracy) converted to **INT8 TFLite — 75% smaller, <80ms on-device**.
- Built for fields with no connectivity: inference runs entirely on the handset.

<sub>Python · MobileNet-V2 · TensorFlow Lite · FastAPI · OpenCV</sub>
